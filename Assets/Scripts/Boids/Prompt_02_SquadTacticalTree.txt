Design a squad-level tactical behavior tree for my Unity starship boid system.

Context:
- One BoidsManager controls a squadron.
- BoidFlockTargetManager already detects enemies and assigns targets.
- BoidCommandController already provides squad commands such as follow, attack, defend, form up, break formation, hold, and return to base.

Task:
- Propose a top-level squad tactical tree.
- Include branches for travel, follow, form up, attack objective, defend anchor, regroup, and retreat.
- Show likely selectors, sequences, conditions, and interrupts.
- Explain how player / AI commands should override or bias the tree.
- Explain how the squad tree should interact with target assignment and command anchors.

Output format:
- Tree overview
- Node responsibilities
- Conditions and abort rules
- Blackboard inputs and outputs
- Recommended first implementation slice
